A32-GDEP073E01: Good Display official sample code for GDEP073E01 (ED2208 controller, 7.3-inch 6-color ACeP 800x480).
Adapted for Seeed Studio reTerminal E1002 (XIAO ESP32-S3).

Pinout (reTerminal E1002):
  SCK  -> GPIO 7
  MOSI -> GPIO 9
  CS   -> GPIO 10
  DC   -> GPIO 11
  RST  -> GPIO 12
  BUSY -> GPIO 13 (Active LOW on ED2208: 0 = busy, 1 = ready/idle)
